# Table S3. VPF-Class coverage, counted in protein-family profiles

VPF-Class carries no column in the host matrix: its released tables classify viral protein families rather than viruses, so no record count exists (see `DECISIONS.md`, entry 11). What it does state can still be reported, in its own unit. **Every number below is a count of profiles and is not comparable with a record count anywhere else in this review.**

A profile carries a distribution over candidate hosts, so the membership ratio decides what a count means. Three cuts are given: **>=30%**, the operating point the article itself uses for host prediction at genus level; **>=50%**, above which a profile can satisfy only one class, so the assignment is unique; and **=100%**, wholly homogeneous profiles.
